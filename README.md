# Frankfurt Life

Eine frühe, unabhängige Open-City-Spielidee mit einer kleinen 3D-Browser-Demo.

## Vorschau
Die Website ist für GitHub Pages vorbereitet. Öffne `index.html` über einen statischen Webhost. Die 3D-Demo lädt Three.js über jsDelivr und benötigt WebGL.

## Steuerung
- **W/A/S/D** oder Pfeiltasten: bewegen
- **Maus**: umsehen (in die Demo klicken, um Maussteuerung zu aktivieren)
- **ESC**: Maussteuerung freigeben

## Entwicklungsstand
- Website und erste kleine 3D-Stadtdemo: Prototyp
- Windows x64 Installer / portable Version: noch nicht gebaut
- Online-Mehrspieler und Voice-Chat: noch nicht implementiert
- Die angezeigten Windows-Downloadkarten sind Platzhalter und keine echten Downloads.
